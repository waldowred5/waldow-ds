# waldow.design

A small but real design system. This Storybook is the design reference: principles, foundations and every component, in light and dark (use the theme switcher in the toolbar).

- **[Principles](?path=/docs/principles-overview--docs):** short, testable rules with do and don't examples. Link to these in critiques.
- **Foundations:** [colour](?path=/docs/foundations-color--docs), [typography](?path=/docs/foundations-typography--docs), and [space, radius and elevation](?path=/docs/foundations-space-radius-and-elevation--docs), all rendered live from `@waldow-ds/tokens`.
- **Components:** each has a docs page with usage, props and accessibility notes, plus stories for every state.

## How it fits together

1. **Tokens** (`@waldow-ds/tokens`): primitive → semantic → component, built to CSS variables with light and dark themes.
2. **Components** (`@waldow-ds/ui`): shadcn/ui on Radix, styled only with Tailwind utilities that map to semantic and component tokens ([ADR 001](https://github.com/waldowred5/waldow-ds/blob/main/docs/adr/001-shadcn-ui-component-foundation.md)).
3. **Quality gates:** every story is rendered and checked with axe in CI, Chromatic reviews visual changes, tokens fail the build below WCAG AA, and bundles have size budgets.
