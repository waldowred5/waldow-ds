# One primary action per surface

**Rule:** A card, dialog, form or page section has at most one `primary` button. Other actions use `secondary`, `outline` or `ghost`.

**Why:** The primary button answers "what should I do here?" Two answers is no answer.

**How to check:** Count `variant="primary"` buttons (the default) in each surface. More than one is a violation.
