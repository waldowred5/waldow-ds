# Typography

One sans family for UI (`--ds-font-body`, Tailwind `font-sans`) and one mono family for code (`--ds-font-code`, `font-mono`). Sizes map to Tailwind's `text-*` utilities.

| Utility | Token | Use for |
| --- | --- | --- |
| `text-xs` | `font-size.xs` | Badges, captions |
| `text-sm` | `font-size.sm` | Controls, table cells, help text (the UI default) |
| `text-base` | `font-size.md` | Body copy |
| `text-lg` | `font-size.lg` | Card and dialog titles |
| `text-xl` – `text-4xl` | `font-size.xl`–`4xl` | Page headings |
